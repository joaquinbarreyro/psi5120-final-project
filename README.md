# PSI5120 Final Project

## Design and Experimental Evaluation of a Cloud-Based IoT System for Electronic Toll Collection

This repository contains the complete submission of the final project developed by JOAQUIN BARREYRO
for the PSI5120 Cloud Computing course at the University of São Paulo (USP).

The project implements and experimentally evaluates an end-to-end IoT prototype
for electronic toll collection using a Raspberry Pi as the edge device and AWS
cloud services for image processing and vehicle authorization.

The repository is organized into three main directories:

```text
psi5120-final-project/
├── paper/
├── raspberry/
├── aws/
└── README.md

paper/
Contains the final IEEE-format paper describing the project.

The paper presents the system architecture, implementation, experimental
methodology, latency measurements, results, and discussion of the proposed
cloud-based electronic toll collection prototype.

raspberry/
Contains the software and experimental data from the Raspberry Pi used as the
edge device of the prototype.
Additional information about the edge application and its directory structure
is available in raspberry/toll-iot/README.md.

aws/
Contains the cloud-side implementation and infrastructure documentation.
Additional information about the AWS resources is available in
aws/README.md.
